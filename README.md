## 🌟 Highlights & Architecture

- **Featured Project — AI-Based Landslide Early Warning & Risk Monitoring System in NER**:
  - Developed for **Smart India Hackathon 2026** (Problem Statement ID: 26001, Team: UI WIZARDS).
  - Multi-source spatial hazard monitoring across all 8 North Eastern Region states.
  - XGBoost risk classifier (**94.6% accuracy**) + YOLO computer vision for road debris detection.
  - Interactive Folium/Leaflet.js GIS risk heatmaps & automated Twilio SMS alert gateway (**<3s dispatch**).
  - GitHub Repo: [NER-Landslide-Early-Warning-System](https://github.com/Tirthdeveloper/NER-Landslide-Early-Warning-System)

- **Air Quality Index (AQI) Analysis & Pollutant Correlation Engine**:
  - Analyzed 9,000+ air quality records across seasonal weather shifts.
  - Data cleaning, outlier treatment, and statistical correlation heatmaps (PM2.5, PM10, NO2, CO).
  - GitHub Repo: [AQI_Analysis](https://github.com/Tirthdeveloper/AQI_Analysis)

- **Hospital Clinical Management Database Architecture**:
  - 3NF normalized MySQL schema across 5+ linked tables.
  - Complex SQL multi-table joins, subqueries, and window functions running in `<40ms`.
  - GitHub Repo: [SQL_FINAL_EXAM](https://github.com/Tirthdeveloper/SQL_FINAL_EXAM)

- **Agricultural Crop Recommendation BI Dashboard**:
  - Power BI interactive reporting dashboard analyzing soil nutrients (N, P, K) and climate metrics.
  - GitHub Repo: [crop_recommendation_powerbi](https://github.com/Tirthdeveloper/crop_recommendation_powerbi)

## 🚀 Getting Started

Clone the repository and launch locally:

```bash
# Clone repository
git clone https://github.com/Tirthdeveloper/TIRTH_PATEL_Portfolio.git

# Enter project directory
cd TIRTH_PATEL_Portfolio

# Run any local server (e.g., Python HTTP Server)
python -m http.server 5173
```

Open `http://localhost:5173` in your browser.
